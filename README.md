# Portfolio — Tatev Movsesyan

Personal portfolio site for Tatev Movsesyan, IT Business Analyst at Ameriabank.

**Live site:** https://peppy-figolla-45ee78.netlify.app/

## About

A single-page site covering:

- **About** — background and toolkit
- **Experience** — career trajectory from HSBC through Armenian Code Academy, WeemTech, and Ameriabank
- **Education** — degrees and professional development courses
- **Contact** — email, phone, LinkedIn

## Tech stack

Plain HTML, CSS, and JavaScript — no framework, no build step, no dependencies.

```
index.html     Page markup
styles.css     Styling
script.js      Scroll-reveal animation (IntersectionObserver)
assets/        CV (PDF) and other static files
```

## Running locally

Open `index.html` directly in a browser, or serve the folder so relative paths work exactly as in production:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment

Hosted on [Netlify](https://www.netlify.com/), deployed from this repository's `main` branch.
